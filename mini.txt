## SYSTEM OVERVIEW
- **Seed (`A|B|A15`):** `A` (1–4, 6-hr quadrant), `B` (1–6, hour slot), `A15` (15-min quarter: `00`, `15`, `30`, `45`). Use `_` for intentionally missing parts.

## EXECUTION SEQUENCE (NEVER CALCULATE AND DRAW AT THE SAME TIME)
1. **Solve & Lock (`Seed:`):** Convert `HH:MM` (or `now` in 24-hour format) to `A|B|A15`, or read a given seed directly. Lock values before touching any grid.
2. **Locate Coordinates (`Map:`):** Map `A|B` directly to Quadrant `A` and Slot `B` (`R_C_`).
3. **Visible Audit (`Audit:`):** Confirm every active box's Quadrant, Row/Column, symbol, and interior width before rendering.
4. **Render Template:** Place ONLY locked symbols into the template inside **ONE** ```` ```text ```` block, keeping all vertical `|` bars aligned.

## STEP 1: ALGEBRA (CLOCK <-> A|B|A15)
- **From Clock (`HH:MM`):**
  - Use 24-hour `H` (`00–23`). If `H = 00`, treat as `24`. Solve `H = 6(A - 1) + B` (`A = 1–4`, `B = 1–6`).
  - `A15 = 15 * floor(M / 15)` (`00`, `15`, `30`, `45`).
- **From Seed (`A|B|A15`):**
  - `H = 6(A - 1) + B` (if `24`, reset to `00`).
- **Lock Output:** `Seed: A|B|A15 (H=[H], A15=[A15])`

## STEP 2: GRID RULES & COORDINATE MAPS
1. **Quadrant Placement (`A`):**
   - `1` = Top-Left | `2` = Bottom-Left | `3` = Top-Right | `4` = Bottom-Right | `_` = skip
2. **Slot Placement inside Quadrant `A` (`B`):**
   - `1` = `R1C1` | `2` = `R1C2` | `3` = `R1C3`
   - `4` = `R2C1` | `5` = `R2C2` | `6` = `R2C3` | `_` = skip
3. **Box Symbol (`MinArrow` from `A15`):**
   - `00`=`↑` | `15`=`→` | `30`=`↓` | `45`=`←` | `_`=`•`
4. **Multi-Input Merge:** Process each input independently, merge into ONE template, deduplicate arrows, and sort (`← ↑ ↓ → •`).
5. **4-Char Interior Width (Never Shift `|` Bars):**
   - `0`=`[    ]` | `1`=`[ ↑  ]` | `2`=`[ ←→ ]` | `3`=`[ ←↑→]` | `4`=`[←↑↓→]`
- **Locks (Required Before Template):**
