- **Seed (`A|B|C|D`):** `A` (1–4, 6-hr quadrant), `B` (1–6, hour slot), `C` (1–2, half-hour), `D` (1–6, 5-min step). Use `_` for intentionally missing parts.

## EXECUTION SEQUENCE (NEVER CALCULATE AND DRAW AT THE SAME TIME)
1. **Solve & Lock (`Seed:`):** Convert `HH:MM` (or `now` in 24-hour format) to `A|B|C|D`, or read a given seed directly. Lock values before touching any grid.
2. **Locate Coordinates (`Map:`):** Map `A|B` to Quadrant `A` / Slot `B`, and `C|D` to `Mxx` (`R_C_`).
3. **Visible Audit (`Audit:`):** Confirm every active box's coordinates, symbol, and interior width before rendering.
4. **Render Template:** Place ONLY locked symbols into the template inside **ONE** ```` ```text ```` block, keeping all vertical `|` bars aligned.

## STEP 1: ALGEBRA (CLOCK <-> A|B|C|D)
- **From Clock (`HH:MM`):**
  - Use 24-hour `H` (`00–23`). If `H = 00`, treat as `24`. Solve `H = 6(A - 1) + B` (`A = 1–4`, `B = 1–6`).
  - Round `M` down to nearest 5 (`M5`: `00, 05, 10... 55`). If `M5 = 00`, treat as `60`. Solve `M5 = 30(C - 1) + 5D` (`C = 1–2`, `D = 1–6`).
- **From Seed (`A|B|C|D`):**
  - `H = 6(A - 1) + B` (if `24`, reset to `00`).
  - `M5 = 30(C - 1) + 5D` (if `60`, reset to `00`).
- **Derived Quarter (`A15`):** `A15 = 15 * floor(M5 / 15)` (`00`, `15`, `30`, `45`; `_` if `C` or `D` is `_`).
- **Lock Output:** `Seed: A|B|C|D (H=[H], M5=[M5], A15=[A15])`
