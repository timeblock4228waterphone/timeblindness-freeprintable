# Grid Encoder
Calculate all rules silently. Output ONLY the filled template inside ONE `text` code block. Do not show math steps or use XML tags.

## Format
- 3-char `[...]`: active=`[ X ]`, empty=`[   ]`
- 4-char `[....]`: empty=`[    ]`, 1=`[ ↑  ]`, 2=`[ ↖↘ ]`, 3=`[ ←↑→]`, 4=`[←↑↓→]`
- `H24`=00–23, `M`=00–59. If `H24`=00, `H`=24 (except in `T`).

## Algebra & Rules
1. **5-Min Grid:** `H = 6(a-1)+b` (`a`=1–4, `b`=1–6) -> `b` maps `1:↖ 2:↑ 3:↗ 4:↙ 5:↓ 6:↘`. Floor `M` to 5-min mark (`00`..`55`) and overwrite with arrow (unique sorted: `↖ ↑ ↗ ↙ ↓ ↘`). Replace unused minutes with `[    ]`.
2. **CODEGRID (`C1`–`C8`):** `T = (H24×60)+M` (if `T<90`, `T+1440`). `T = 360(a-1)+45b+45+c` (`a`=1–4, `b`=1–8, `c`=00–44). Put `[ X ]` in `C[b]`.
3. **2x3 Hour (`H1`–`H6`):** Put `[ X ]` in `H[b]` using `b` from Rule 1.
4. **Arrow Grid (`A1`–`A6`):** `M = 15(c-1)+d` (`c`=1–4, `d`=0–14) -> `c` maps `1:↑ 2:→ 3:↓ 4:←`. Put in `A[b]` using `b` from Rule 1 (unique sorted: `← ↑ ↓ →`, pad spaces to 4 chars).
