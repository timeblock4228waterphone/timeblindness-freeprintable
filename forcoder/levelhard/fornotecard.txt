## GRID RULES & AUTHORITATIVE COORDINATES
1. **HOUR (Quadrant First, Math Second):** Treat `00` as `24`.
   - **Step A — Locate Quadrant `Ha` (2×2 Grid, by hour range / `a`):**
     - `R1:` `01–06` (`a=1`) → `H1` | `13–18` (`a=3`) → `H3`
     - `R2:` `07–12` (`a=2`) → `H2` | `19–24` (`a=4`) → `H4`
   - **Step B — Solve `b = H - 6(a - 1)` (`1–6`) & Select `HourArrow`:**
     - `b=1` (`↖`) | `b=2` (`↑`) | `b=3` (`↗`) | `b=4` (`↙`) | `b=5` (`↓`) | `b=6` (`↘`)
2. **MINUTE (`Mxx`) & `MinArrow`:**
   - `A15 = 15 * floor(M / 15)` (`00`=`↑`, `15`=`→`, `30`=`↓`, `45`=`←`)
   - `R15 = M - A15` (`0–14`), `S5 = 5 * floor(R15 / 5)` (`0,5,10`), `r = R15 - S5` (`0–4`)
   - `Mxx = A15 + S5` (`M00`–`M55`)
   - **M-Grid Map (4×3):** `R1:` M05, M10, M15 | `R2:` M20, M25, M30 | `R3:` M35, M40, M45 | `R4:` M50, M55, M00.
3. **MIN-ARROW (`MinArrow`):** `00–14`=`↑` | `15–29`=`→` | `30–44`=`↓` | `45–59`=`←`.
4. **A-Grid Map (2×3, by `b`):** `R1:` `b=1`→A1, `b=2`→A2, `b=3`→A3 | `R2:` `b=4`→A4, `b=5`→A5, `b=6`→A6.
5. **CODGRID (`Cd`, 2×4, by `d`):**
   - `T = 60H + M` (if `T < 90`, add `1440`). `U = T - 90`.
   - `q = floor(U / 360)` (`0–3`), `R = U - 360q` (`0–359`).
   - Calculate `d` and `c` **strictly from `R`, never directly from `U`**: `d = floor(R / 45) + 1` (`1–8`), `c = R mod 45` (`0–44`).
   - Verify `90 + 360q + 45(d - 1) + c = T`.
   - **CODGRID Map (2×4):** `R1:` C1, C2, C3, C4 | `R2:` C5, C6, C7, C8.

## SYSTEM OVERVIEW
- **Seed (`A|B|C|D`):** `A` (1–4, 6-hr quadrant), `B` (1–6, hour slot), `C` (1–2, half-hour), `D` (1–6, 5-min step). Use `_` for intentionally missing parts.

1. **Solve & Lock (`Seed:`):** Convert `HH:MM` (or `now` in 24-hour format) to `A|B|C|D` and `t`, or read a given `A|B|C|D` seed directly. Lock values before touching any grid.
2. **Locate Coordinates (`Map:`):** Map every active box to its exact Row/Column (`R_C_`).

## STEP 1: ALGEBRA (CLOCK <-> A|B|C|D -> t)
- **From Clock (`HH:MM`):**
  - Use 24-hour `H` (`00–23`). If `H = 00`, treat as `24`. Solve `H = 6(A - 1) + B` (`A = 1–4`, `B = 1–6`).
  - Round `M` down to nearest 5 (`M5`: `00, 05, 10... 55`). If `M5 = 00`, treat as `60`. Solve `M5 = 30(C - 1) + 5D` (`C = 1–2`, `D = 1–6`).
- **From Seed (`A|B|C|D` -> `t`):**
  - `H = 6(A - 1) + B` (if `24`, reset to `00`).
  - `M5 = 30(C - 1) + 5D` (if `60`, reset to `00`).
  - `t = 60(H) + M5` (leave `t` blank if any digit is `_`).
- **Lock Output:** `Seed: A|B|C|D | t=[t] (H=[H], M5=[M5])`
