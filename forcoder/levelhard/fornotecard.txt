## EXECUTION & SYMBOL LOCK (STRICT 6-STEP ORDER)
Never calculate and draw at the same time. For every input (`24:xx = 00:xx`), follow this exact sequence:
1. **Locate & Calculate:**
   - **Hour (Quadrant First, Math Second):** Find quadrant `Ha` (`a=1–4`) from the hour range first, then solve `b = H - 6(a - 1)` (`1–6`).
   - **Minute & CODGRID:** Solve `m`, `r`, `T`, `U`, `q`, `R`, `d`, `c`.
2. **Lock** values in `Calc:` (and `Merge:` for multi-input) before touching the template.
3. **Locate & Lock Box Coordinates:** Map every calculated ID to its exact Row/Column from the Coordinate Maps and lock it in `Map:`:
   - Format: `Map: Ha=R[x]C[y] (HourArrow) | Mxx=R[x]C[y] (HourArrow) | Ab=R[x]C[y] (MinArrow) | Cd=R[x]C[y] ([ X ])`
4. **Select & Place:** Insert locked symbols into the template using ONLY the `Map:` coordinates (never infer from visual order).
5. **Visible Audit:** Output an `Audit:` line confirming every active box's Row/Column, symbol type, and character width before rendering the template:
   - Format: `Audit: H-Grid[R_,C_=HourArrow OK] | M-Grid[R_,C_=HourArrow OK] | A-Grid[R_,C_=MinArrow OK] | CODGRID[R_,C_=X OK]`
6. **Audit** placement before outputting.

## GRID RULES & AUTHORITATIVE COORDINATES
1. **HOUR (Quadrant First, Math Second):** Treat `00` as `24`.
   - **Step A — Locate Quadrant `Ha` (2×2 Grid, by hour range / `a`):**
     - `R1:` `01–06` (`a=1`) → `H1` | `13–18` (`a=3`) → `H3`
     - `R2:` `07–12` (`a=2`) → `H2` | `19–24` (`a=4`) → `H4`
   - **Step B — Solve `b = H - 6(a - 1)` (`1–6`) & Select `HourArrow`:**
     - `b=1` (`↖`) | `b=2` (`↑`) | `b=3` (`↗`) | `b=4` (`↙`) | `b=5` (`↓`) | `b=6` (`↘`)
2. **MINUTE (`Mxx`):** Solve `M = 5m + r` (`m=0–11`, `r=0–4`); format box as `M` + 2-digit `5m` (`M00`–`M55`).
   - **M-Grid Map (4×3):** `R1:` M05, M10, M15 | `R2:` M20, M25, M30 | `R3:` M35, M40, M45 | `R4:` M50, M55, M00.
3. **MIN-ARROW (`MinArrow`):** `00–14`=`↑` | `15–29`=`→` | `30–44`=`↓` | `45–59`=`←`.
4. **A-Grid Map (2×3, by `b`):** `R1:` `b=1`→A1, `b=2`→A2, `b=3`→A3 | `R2:` `b=4`→A4, `b=5`→A5, `b=6`→A6.
5. **CODGRID (`Cd`, 2×4, by `d`):**
   - `T = 60H + M` (if `T < 90`, add `1440`). `U = T - 90`.
   - `q = floor(U / 360)` (`0–3`), `R = U - 360q` (`0–359`).
   - Calculate `d` and `c` **strictly from `R`, never directly from `U`**: `d = floor(R / 45) + 1` (`1–8`), `c = R mod 45` (`0–44`).
   - Verify `90 + 360q + 45(d - 1) + c = T`.
   - **CODGRID Map (2×4):** `R1:` C1, C2, C3, C4 | `R2:` C5, C6, C7, C8.
