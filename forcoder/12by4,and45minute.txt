System Prompt Recipe: The 3x4 Grid-Clock App

Objective

Build a web application that displays a custom sequence of times mapped onto a physical 3x4 number grid. The grid must highlight the current hour box and display a directional arrow inside that box based on the minutes.

The Visual Layout (The 3x4 Grid)

Create a central grid container on the screen.

Force a strict layout of 3 columns across and 4 rows down (3x4 matrix).

Generate 12 empty square boxes numbered sequentially from 1 to 12.

They must automatically arrange themselves exactly like this:

Row 1: 1, 2, 3

Row 2: 4, 5, 6

Row 3: 7, 8, 9

Row 4: 10, 11, 12

The Custom Time Dataset

The system does not run on a real-time clock. Instead, it holds an array of specific timestamps and tracks the active index. Here is the strict sequence:
1:30, 2:15, 3:00, 3:45, 4:30, 5:15, 6:00, 6:45, 7:30, 8:15, 9:00, 9:45, 10:30, 11:15, 12:00, 12:45

3. The UI Controls

Display the currently selected time in a large, clear digital readout above or below the grid.

Add a button labeled "Next Time".

Clicking this button must advance the system to the next time slot in the sequence. If the user clicks it at 12:45, it must cleanly loop back to the first time (1:30).

The Matching Logic (Run on every step)

Every time a new timestamp is selected, clear all existing highlights and arrows from the grid, read the current Hour and Minute, and apply these two rules:

Rule A: Find the Grid Box (The Hour)

Convert the hour to a standard 12-hour format (e.g., if the hour is 00, target Box 12. If the hour is 13, subtract 12 to target Box 1. For hours 1 through 12, target that exact matching box number).

Make that targeted grid box visually light up/highlight with a bright background color.

Rule B: Choose the Arrow Direction (The Minutes)

Look at the minute value of the active time slot.

If minutes are between 0 and 14: Choose the ↑ arrow.

If minutes are between 15 and 29: Choose the → arrow.

If minutes are between 30 and 44: Choose the ↓ arrow.

If minutes are between 45 and 59: Choose the ← arrow.

Render this chosen arrow large and clear directly inside the active, lit-up grid box next to its number. All other boxes remain empty.
