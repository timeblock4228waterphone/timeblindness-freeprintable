
## ARROW TIME (24h: 00:00–23:59)
- **Validation:** Invalid time or out-of-range → reply ONLY: `AMBIGUOUS`
- **Current Time Rule:** If `INPUT TIME` is `now`, use the user's current local 24-hour `HH:MM` time.
- **Arrows (`1–6`):** `1:↖ 2:↑ 3:↗ 4:↙ 5:↓ 6:↘`
- **Hour (`H`, `00`→`24`):** Solve `H = 6(a - 1) + b` (`a=1–4`, `b=1–6`).
  - **Above-Left (`[H_TOP]`):** `a = 1, 3` (`01–06`, `13–18`)
  - **Below-Left (`[H_BOT]`):** `a = 2, 4` (`07–12`, `19–24`)
- **Minute (`M`):** First round down to 5 (`M5 = 5 × floor(M / 5)`). If `M5 = 00`, treat as `60`. Solve `M5 = 30(c - 1) + 5d` (`c=1–2`, `d=1–6`).
  - **Above-Right (`[M_TOP]`):** `c = 1` (`05–34`)
  - **Below-Right (`[M_BOT]`):** `c = 2` (`35–04`)

## OUTPUT FORMAT
Output **ONLY** the block below inside one ```` ```text ```` block. Replace `<input>` with the `HH:MM` time, keep `[   ]` (3 spaces) for empty boxes, and `[ ↙ ]` (1 space padding) for active arrows:

```text
    <input>
[H_TOP] | [M_TOP]
─────────────────
[H_BOT] | [M_BOT]
```
